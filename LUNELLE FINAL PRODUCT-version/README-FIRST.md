# LUNELLE — Complete starter website bundle

This bundle contains two separate visual versions of the LUNELLE beauty storefront. Both are plain HTML, CSS and JavaScript and can be opened locally in a browser.

## Version 1 — Homepage concept
Open `01-homepage-version/lunelle_homepage/index.html`. This is the original editorial homepage concept with sample product content and interactive demo elements.

## Version 2 — Shop and product experience (recommended for testing the shopping journey)
Open `02-shop-product-version/index.html`. Use **Shop** to browse and filter products, open a product detail page, add items to the shared bag, and open `cart.html` to edit quantities and submit an order enquiry to WhatsApp. `help.html` explains the current demo policies.

## How to open
1. Extract this ZIP to a folder.
2. Keep the files and folders together.
3. Double-click the `index.html` in the version you want to view.
4. For best results, use a current version of Chrome, Edge or Firefox. Some browser privacy settings may restrict local storage; use a simple local server if the bag does not retain items between pages.

## Important limitations
This is a static front-end starter, not a hosted production store. The cart is stored in the current browser using local storage. Checkout sends an order enquiry to WhatsApp; it does not create a server-side order, reserve stock, send email automatically, or collect payment. There is no admin dashboard, secure database, inventory management, real payment gateway, automated shipping integration, customer accounts, or verified reviews. Those features require a backend, hosting and service accounts. Do not describe a WhatsApp enquiry as a confirmed order. Never ask customers for PINs or one-time codes.

## Before publishing publicly
Replace all sample content, verify contact information, confirm delivery and return policies, add licensed product images, test on phone and desktop, set up HTTPS hosting, and connect a secure backend/payment provider if real online payment is needed. Consider getting help from a trusted adult or qualified developer before handling customer personal information or payments.
