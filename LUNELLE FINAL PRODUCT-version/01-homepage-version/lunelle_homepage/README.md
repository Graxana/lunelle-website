# LUNELLE — Part 1 Homepage

This is a static, responsive homepage built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — homepage structure and page content
- `styles.css` — responsive layout and blush/cream/rose-gold styling
- `script.js` — sample product cards, category filtering, search suggestions, wishlist, demo cart and newsletter feedback
- `assets/lunelle-homepage-concept.png` — visual design concept reference, if included

## Run it on your computer
1. Download and unzip `lunelle-homepage.zip`.
2. Open the `lunelle-homepage` folder.
3. Double-click `index.html` to open it in your browser.
4. For a better development workflow, open the folder in Visual Studio Code and use the Live Server extension.

The page uses Google Fonts when internet is available. It still falls back to system fonts if the font service cannot load.

## Important before launch
- Product names, prices, ratings, and product visuals are demo content. Replace them with real products and genuine customer reviews.
- The cart and newsletter form are front-end demos only. No order is submitted and no email is stored.
- Customer accounts, payment processing, real stock/order management, secure checkout, and admin tools require a backend and are not part of this homepage-only stage.
- Update delivery terms and the free-delivery offer to match your actual business policy before publishing.
- Use your own product photos and ensure you have permission to use any images.
- Connect the domain and host the files on a static hosting service (for example, GitHub Pages or Netlify) when ready.
